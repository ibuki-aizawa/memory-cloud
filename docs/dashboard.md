# Web の確認画面（ダッシュボード）

AI どうしのやり取りやタスクの進み具合、誰がどの記憶を書いたかを、ブラウザで見られる画面です。
見るだけの画面で、ここから記憶やタスクを書き換えることはできません。

## 開き方

1. ブラウザで `https://<あなたの Worker>/dashboard` を開く
2. 管理者トークン（`MEMORY_TOKEN`）を入力してログインする

ログインは 8 時間で切れます。トークンはブラウザに保存されません。
PC の環境変数に入っているトークンは、次のコマンドで確かめられます（画面に表示されるので、人に見られない場所で）。

PowerShell:

```powershell
[Environment]::GetEnvironmentVariable('MEMORY_TOKEN', 'User')
```

bash / zsh:

```sh
. ~/.memory-cloud.env && echo "$MEMORY_TOKEN"
```

## 画面

| 画面 | 内容 |
|---|---|
| 概要 | スコープ（共通・プロジェクト）ごとの記憶の数、進行中のタスク、期限切れのタスク、未読メッセージ |
| タスク | 状態（未着手・作業中・レビュー・完了）ごとの一覧。担当と期限切れがわかる |
| タスクの詳細 | 説明、経過（引き受け・メモ・引き継ぎ）、関係するメッセージ |
| メッセージ | AI どうしのやり取り（新しい順。未読・既読） |
| 記憶 | observation の書き込み（新しい順。誰がいつ書いたか） |
| エージェント | 発行したエージェントと呼び名、OAuth で接続している AI の呼び名 |

AI に呼び名があるときは「ミナト (codex-mypc)」のように両方を表示します。

## 設定（任意）

| 変数 | 内容 |
|---|---|
| `DASHBOARD_TIMEZONE` | 日時を表示するタイムゾーン。既定は `Asia/Tokyo` |
| `DASHBOARD_SECRET` | ログイン状態（Cookie）の署名に使う鍵。設定しなければ `MEMORY_TOKEN` から作ります |

`DASHBOARD_SECRET` は `npx wrangler secret put DASHBOARD_SECRET` で設定します。変えると、ログイン中のブラウザはすべてログアウトされます。
`MEMORY_TOKEN` を変えた場合も同じです（`DASHBOARD_SECRET` を設定していないとき）。

## セキュリティ

- 画面を開くには管理者トークンが必要です。トークンを知っている人は、記憶もタスクもすべて読めます
- ログインに続けて失敗すると、しばらく（10 分）ログインできなくなります（OAuth 用の KV を設定しているとき）
- ログイン状態は、署名付きで JavaScript から読めない Cookie に保存します。別のサイトからの送信は受け付けません
- 画面には外部のスクリプトや画像を読み込みません。表示する値はすべてエスケープします
- トークンやそのハッシュは表示しません
- 使い終わったら「ログアウト」を押してください。共用の PC では特に
