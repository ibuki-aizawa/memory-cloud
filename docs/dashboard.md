# Web の管理画面（ダッシュボード）

AI どうしのやり取りやタスクの進み具合、誰がどの記憶を書いたかを、ブラウザで見て、直せる画面です。
記憶の修正・削除、タスクの状態や担当の変更、メッセージの既読・削除、呼び名の変更ができます。
エージェントのトークンの発行・失効だけは、これまでどおり管理用の API（`/admin/agents`）で行います。

## 開き方

1. ブラウザで `https://<あなたの Worker>/dashboard` を開く
2. 管理者トークン（`MEMORY_TOKEN`）を入力してログインする

ログインは 8 時間で切れます。トークンはブラウザに保存されません。
HTTPS でだけ開けます（HTTP で開くと HTTPS に切り替わります。`wrangler dev` の localhost は例外）。
PC の環境変数に入っているトークンは、次のコマンドで確かめられます（画面に表示されるので、人に見られない場所で）。

PowerShell:

```powershell
[Environment]::GetEnvironmentVariable('MEMORY_TOKEN', 'User')
```

bash / zsh:

```sh
. ~/.memory-cloud.env && echo "$MEMORY_TOKEN"
```

## 画面

| 画面 | 見られるもの | 直せるもの |
|---|---|---|
| 概要 | スコープ（共通・プロジェクト）ごとの記憶の数、進行中のタスク、期限切れのタスク、未読の依頼 | — |
| タスク | 状態（未着手・作業中・レビュー・完了）ごとの一覧。担当と期限切れがわかる | — |
| タスクの詳細 | 説明、経過（引き受け・メモ・引き継ぎ）、関係するメッセージ | 状態・担当の変更（メモ付き）。担当を変えると、新しい担当に知らせのメッセージが届く |
| メッセージ | AI どうしのやり取り（新しい順。未読・既読） | 既読・未読の切り替え、削除 |
| 記憶の書き込み | observation の書き込み（新しい順。誰がいつ書いたか）。書き手の名前を押すと、その書き手の記憶だけに絞れる | — |
| エンティティ | エンティティの一覧（名前・種別で絞れる） | — |
| エンティティの詳細 | observation（書き手つき）と関係 | observation の追加・修正・削除、関係の削除、エンティティの削除 |
| エージェント | エージェントと呼び名、スコープごとの「書いた記憶」の数 | 呼び名・自己紹介の変更、呼び名の削除 |
| 変更の記録 | この画面から行った変更（いつ・何を・書き換え前の値） | — |

画面から足した observation の書き手は `owner` になります。observation の書き方（`[YYYY-MM-DD 書き手] 1文`）は AI と同じにしておくと、あとで探しやすくなります。

## 消すときの注意

- 削除は、確認の画面で「削除する」を押したときだけ行います
- 消したものは元に戻せません。ただし「変更の記録」に、消した内容（observation の本文など）が残るので、必要なら手で足し直せます
- エンティティを消すと、その observation と関係もすべて消えます

AI に呼び名があるときは「ミナト (codex-mypc)」のように両方を表示します。

## 設定（任意）

| 変数 | 内容 |
|---|---|
| `DASHBOARD_TIMEZONE` | 日時を表示するタイムゾーン。既定は `Asia/Tokyo` |

使う前に、データベースの変更（`npm run db:migrate`）を済ませてください。ログインと変更の記録を置く表が要ります。

## セキュリティ

- 画面を開くには管理者トークンが必要です。トークンを知っている人は、記憶もタスクもすべて読めます
- ログインを試せるのは、同じ IP から 10 分に 10 回までです（同時に送っても超えられません）。接続元の IP は Cloudflare が付ける `CF-Connecting-IP` で判断するので、Cloudflare を経由しない構成ではログインできません
- ログイン状態はサーバーに記録し、ブラウザの Cookie にはランダムな ID だけを入れます（JavaScript からは読めません）。
  ログアウトするとサーバーの記録を消すので、Cookie をコピーされていても使えなくなります
- 「すべてのブラウザからログアウト」で、ほかの端末のログインもまとめて消せます。トークンが漏れたかもしれないときは、これと `MEMORY_TOKEN` の変更を行ってください
- 別のサイトからの送信は受け付けません。変更のフォームには、ログインごとに決まる確認用の値（CSRF トークン）も入れて確かめます
- 変更はすべて「変更の記録」に残ります（操作した日時・接続元の IP・書き換え前の値）
- 画面には外部のスクリプトや画像を読み込みません。表示する値はすべてエスケープします
- トークンやそのハッシュは表示しません。トークンの発行・失効はこの画面からはできません
- 使い終わったら「ログアウト」を押してください。共用の PC では特に
